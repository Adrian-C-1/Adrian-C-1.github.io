Mmph, pies…

#Solve

Finally one that has PIE enabled.

3 is useless.

2 checkout has a gets input. The function BookOfTheDead gives us a pointer to itself:

The function Necronomicon gives us a libc pointer!

You wander the dusty shelves and see:

  • SpiceLatte.txt
  • libc.so.6
  • run
  • Cursed_Library
  • ld-linux-x86-64.so.2
  • Necronomicon.txt
  • PumpkinBread.txt

We have to find a way to get shell control.

Some interesting finds:

  • libc .rodata:00000000001AAEA4 aBinSh db '/bin/sh',0 ; DATA XREF: sub_542E0+183↑o
  • libc 0x054790 system ( rdi = command )
  • libc 0x000000000002a9b7 : pop rdi ; ret

So the general path is:

  1. Get pointer to BookOfTheDead.
  2. Buffer overflow checkout to return to Necronomicon and get libc pointer.
  3. Calculate offsets to /bin/sh string, system function, and gadget.
  4. After Necronomicon, buffer overflow checkout again to return to gadget, pop the string, and call system.

End of the note. Beginning of the rabbit hole.
