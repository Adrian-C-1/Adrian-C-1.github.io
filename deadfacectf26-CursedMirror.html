Libc functions for reference:

The main issue is how it will handle the strcpy and reversing of the data.

Since dest is below src, we should be fine. Win function is at 0x40180D, executes whatever we put in rdi.

ROP gadgets:

question is at 0x4019E3. La iesire, rcx are pointer catre input[1] (ignora primul caracter). Nu avem gadgeturi cu rcx. rax are 0xA. 0x0000000000401da7 : pop rsi ; pop rdx ; ret Avem 0x0000000000401da5 : pop rdi ; ret, dar trebuia sa aflam cumva pointerul catre inputul nostru. We can call question again, if that’s useful somehow. La 0x0406188 am /bin/sh invers, trb reversed. reflect e la 0x401950 si da reverse la un string din rdi.
